## 1. 产品概述

### 1.1 一句话产品

Pose相机是一款结合摄影知识库与 AI 视觉的人像拍照伴侣工具：
- **拍摄者**打开相机，AI 实时告诉 TA 该站哪儿、用什么焦段/倍数、怎么构图；
- **被拍摄者**通过 AR 姿势引导线知道怎么摆、往哪看、做什么表情；
- 同时给拍摄者备好能调动对方情绪的「话术锦囊」，让拍照从「沉默社死」变成「开心互动」。

### 1.2 产品目标

让每个人都能拍出「有情绪、有构图、有故事」的人像照片，降低人像摄影的门槛，同时改善关系场景中的拍照体验。

### 1.3 目标用户

| 优先级 | 用户类型 | 核心场景 | 痛点 |
|---|---|---|---|
| P0 | 情侣/夫妻 | 约会、旅行、纪念日 | 一方拍不好，另一方不满意，容易吵架 |
| P1 | 闺蜜群体 | 探店、Citywalk、旅行 | 姿势重复、构图单调、照片缺乏高级感 |
| P2 | 年轻女性自拍/他拍 | 日常、节日、社交分享 | 不会摆姿势、拍出来不自然 |
| P3 | 亲子家庭 | 公园、旅行、生日 | 孩子不配合、抓拍不到好表情 |

### 1.4 成功指标

| 指标 | MVP 目标 | 说明 |
|---|---|---|
| 激活率 | ≥ 60% | 下载后完成首次拍摄引导 |
| 次日留存 | ≥ 30% | 用户第二天再次打开 |
| 单会话拍摄数 | ≥ 8 张 | 用户愿意多次尝试 |
| NPS | ≥ 40 | 用户愿意推荐给朋友 |
| 付费转化率 | ≥ 3% | MVP 阶段以验证付费意愿为主 |

## 2. 用户故事

### 2.1 核心用户故事

> **作为** 拍照小白的男朋友，  
> **我希望** 在约会拍照时能得到实时指导，  
> **从而** 拍出女朋友满意的照片，同时避免尴尬和抱怨。

> **作为** 被拍摄的女朋友，  
> **我希望** 看到屏幕上直观的姿势引导，  
> **从而** 知道手放哪、头转向哪、表情怎么做，拍出来更自然。

> **作为** 拍摄者，  
> **我希望** App 能告诉我此刻该说什么话来调动对方情绪，  
> **从而** 让拍照过程变得轻松有趣，而不是沉默对峙。

### 2.2 扩展用户故事

> **作为** 闺蜜聚会中的一员，  
> **我希望** 快速找到适合当前场景的姿势模板，  
> **从而** 拍出有氛围感的合照。

> **作为** 想提升摄影技巧的用户，  
> **我希望** 每次拍摄后能看到 AI 点评，  
> **从而** 逐渐学会构图和用光。

## 3. 核心功能需求

### 3.1 功能架构

```
PoseCam MVP
├── 拍摄模式
│   ├── 情侣模式（MVP 核心）
│   ├── 闺蜜模式
│   └── 亲子模式
├── 实时引导层
│   ├── 被拍者：AR 姿势轮廓线
│   ├── 拍摄者：构图框 + 焦段建议
│   └── 双方：情绪话术锦囊
├── 拍摄后
│   ├── AI 点评（构图/姿势/光线）
│   └── 一键保存/分享
└── 模板库
    ├── 场景模板（咖啡馆/海边/展览等）
    └── 姿势模板（单人/双人/互动）
```

### 3.2 MVP 功能清单（Kano 分类）

#### 基本型需求（Must-have）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 相机取景器 | 实时预览，支持前后置摄像头切换 | P0 |
| AR 姿势引导线 | 在取景框中叠加半透明人形轮廓，引导被拍者摆姿 | P0 |
| 构图辅助框 | 显示三分线/中心构图等参考线 | P0 |
| 焦段建议 | 根据场景推荐 1x/2x/3x 等焦段 | P0 |
| 话术锦囊 | 根据场景和拍摄状态，给拍摄者推荐引导语 | P0 |
| 情侣模式 | 默认模式，优化双人互动姿势和站位 | P0 |

#### 期望型需求（Should-have）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 场景识别 | 自动识别咖啡馆/海边/室内等场景 | P1 |
| 姿势模板库 | 提供 20-50 个精选姿势模板 | P1 |
| AI 拍摄点评 | 拍摄后对构图、姿势、光线给出文字点评 | P1 |
| 语音引导 | 用语音播报姿势调整和话术 | P1 |
| 拍摄参数显示 | 显示当前 ISO、快门、对焦距离等（供学习） | P2 |

#### 兴奋型需求（Delighter）

| 功能 | 描述 | 优先级 |
|---|---|---|
| 情绪识别 | 识别被拍者表情，提示"笑一点""眼神看镜头" | P2 |
| 光线分析 | 提示逆光/侧光/顶光，建议调整站位 | P2 |
| 社交分享卡片 | 生成"前后对比 + 拍摄技巧"的分享图 | P3 |
| 社区/挑战赛 | 用户上传姿势和成片，形成 UGC | P3 |

### 3.3 详细功能说明

#### 3.3.1 AR 姿势引导线

- **触发条件**：用户选择姿势模板后，在取景框中显示对应姿势的半透明轮廓。
- **视觉样式**：
  - 轮廓线颜色：白色或浅蓝色，透明度 60-70%；
  - 当用户姿势与模板匹配度 ≥ 80% 时，轮廓变绿并轻微震动提示；
  - 未匹配部位用红色高亮提示。
- **交互**：
  - 支持双指缩放调整轮廓大小；
  - 支持左右翻转轮廓以适配不同站位。

#### 3.3.2 构图辅助框

- **显示内容**：
  - 三分法网格线；
  - 人物头部/眼睛建议落点；
  - 地平线参考线（风景人像）。
- **动态提示**：当手机倾斜或主体偏离建议位置时，显示箭头提示调整方向。

#### 3.3.3 焦段建议

- **推荐逻辑**：
  - 全身照 → 1x 或 0.5x；
  - 半身照 → 1x 或 2x；
  - 特写 → 2x 或 3x；
  - 环境人像 → 1x。
- **显示方式**：在快门按钮附近以小标签形式显示推荐焦段，点击切换。

#### 3.3.4 话术锦囊

- **触发时机**：
  - 拍摄前：建议开场白，帮助放松气氛；
  - 拍摄中：根据被拍者状态给出实时引导语；
  - 拍摄后：给出正向反馈和鼓励。
- **内容示例**：
  - "你靠在那个栏杆上，头稍微歪一点，对，就是这样。"
  - "笑一个，想象一下我欠你 500 块钱没还。"
  - "这张很有感觉，我们再来一张你回头看我的。"
- **生成方式**：
  - MVP 阶段使用预设话术库 + 简单规则匹配；
  - 后续接入 LLM API 动态生成。

#### 3.3.5 AI 拍摄点评

- **点评维度**：
  - 构图（三分法、对称、引导线）
  - 姿势（自然度、肢体协调）
  - 光线（曝光、逆光、阴影）
  - 表情（眼神、笑容）
- **输出形式**：
  - 评分（1-5 星）
  - 3-5 条具体改进建议
  - 1 条正向鼓励

## 4. 非功能需求

### 4.1 性能

| 指标 | 要求 |
|---|---|
| 相机启动时间 | ≤ 2 秒 |
| AR 姿势检测延迟 | ≤ 200ms |
| 构图建议刷新率 | ≥ 15fps |
| 单次拍摄到成片 | ≤ 1 秒 |
| App 包大小 | ≤ 150MB（MVP） |

### 4.2 兼容性

- **MVP 阶段**：优先支持 iOS 16+（ARKit 6 + Apple Vision 框架）。
- **后续阶段**：扩展 Android（ARCore + MediaPipe）。

### 4.3 隐私与安全

- 所有人像分析优先在**端侧**完成，不上传原始图像；
- 仅在使用 AI 点评和云模板时上传必要的低分辨率图像/元数据；
- 明确隐私政策，告知用户数据使用方式。

### 4.4 可访问性

- 支持系统字体大小设置；
- 关键引导信息同时提供视觉和语音反馈；
- 考虑色盲用户对红绿提示的识别问题，使用形状+颜色双重编码。

## 5. 技术路线（草案）

### 5.1 推荐技术栈

| 层级 | 技术选型 | 说明 |
|---|---|---|
| 客户端 | Swift + SwiftUI | 原生体验好，ARKit/Vision 集成成熟 |
| AR/视觉 | ARKit 6 + Apple Vision | 实时人体姿态、场景理解、构图分析 |
| 端侧 ML | Core ML / MediaPipe（备选） | 姿态估计、场景分类 |
| 后端 | Firebase / Supabase（MVP） | 快速搭建用户、模板、点评服务 |
| AI 生成 | OpenAI/Claude/国产大模型 API | 话术生成、拍摄点评 |
| 数据存储 | CloudKit / AWS S3 | 用户照片、模板资源 |

### 5.2 关键技术风险

| 风险 | 影响 | 应对 |
|---|---|---|
| AR 姿态估计精度不足 | 用户姿势引导不准，体验差 | 先使用 2D 轮廓，降低精度要求；逐步引入 3D 骨骼 |
| 不同机型相机差异大 | 焦段/参数建议不准 | 建立机型映射表，MVP 先覆盖主流 iPhone |
| 实时计算耗电高 | 用户拍摄时手机发热 | 优化模型，必要时降帧；提供省电模式 |
| 话术生成延迟 | 影响实时体验 | MVP 用本地话术库，云端作为增强 |

## 6. 产品路线图

### 6.1 MVP 阶段（0-2 个月）

目标：验证核心假设——用户是否愿意为「双向引导 + 情绪话术」买单。

- 实现情侣模式核心 triad：AR 姿势引导 + 构图/焦段建议 + 话术锦囊
- 内置 20 个基础姿势模板
- 支持 5 个常见场景（咖啡馆、海边、展览、公园、室内）
- AI 拍摄点评（基础版）
- iOS 端上线 TestFlight

### 6.2 阶段二（2-4 个月）

- 扩展闺蜜模式、亲子模式
- 姿势模板库扩展至 100+
- 接入 LLM 动态生成话术
- 增加光线分析和表情识别
- 上线 App Store，启动付费订阅

### 6.3 阶段三（4-8 个月）

- Android 版本
- 社区/UGC 姿势模板
- 机位地图（参考可颂）
- 高级会员功能（专业摄影课程、RAW 导出等）
