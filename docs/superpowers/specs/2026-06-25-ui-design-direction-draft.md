## 1. 调研核心结论

### 1.1 相机类 App UI 共识
- **取景器优先**：Halide、Lightroom Mobile、VSCO、原生 iOS 相机均把取景画面放到最大，控制元素极度克制。
- **深色模式是默认**：暗光拍摄、户外强光、OLED 屏幕特性决定深色 UI 为相机类 App 最优解。
- **关键控件放在拇指区**：快门、变焦、切换镜头放在屏幕底部或两侧边缘。
- **iOS 26 趋势**：Apple 新推 **Liquid Glass** 设计语言——半透明覆盖层、毛玻璃质感、控件悬浮在取景画面上方。

### 1.2 AR 叠加层设计原则（Apple HIG / AR 最佳实践）
- **最大化现实世界画面**：AR 元素不能遮挡主体。
- **减少环境中文本**：必要信息放到屏幕空间（screen space），而非 3D 空间中。
- **即时反馈**：姿势匹配成功时，轮廓颜色变化 + 轻微震动。
- **避免视野过载**：同时出现的引导信息不超过 2-3 个。

### 1.3 2025 移动 UI 趋势
- 深色模式 + 自适应对比度
- 玻璃拟态 / 半透明覆盖层
- 柔和圆角与大触控区域
- 微交互作为功能反馈，而非装饰
- 功能型 AI：AI 建议要自然融入流程，避免弹窗打断

## 2. 给 PoseCam 的专业建议

基于「情侣约会拍照」核心场景，建议走 **"专业但不冰冷，温馨但不幼稚"** 的路线：

| 设计要素 | 建议 |
|---|---|
| 主色调 | 深黑/深蓝灰背景 + 青色/蓝绿色（#00D4AA 附近）作为品牌引导色 |
| 辅助色 | 暖白文字、柔灰次级信息、成功绿 / 警示红用于 AR 匹配反馈 |
| 字体 | SF Pro / PingFang SC，确保户外强光下可读 |
| 取景器 | 全屏沉浸式，UI 控件半透明、边缘分布 |
| AR 轮廓 | 虚线轮廓，匹配前青色，匹配后绿色，未匹配部位红色高亮 |
| 信息层级 | 画面 > AR 轮廓 > 底部快门区 > AI 摄影师面板/话术锦囊 |
| 面板风格 | 毛玻璃/半透明卡片，避免纯黑块遮挡画面 |

## 3. 三个候选视觉方向

### 方案 A：专业科技风（Agent 推荐）
- 深黑背景 + 青色点缀
- 取景器全屏，控件极简
- AI 摄影师面板用毛玻璃卡片
- 强调「AI 视觉」和「摄影专业感」
- **适合人群**：对拍照有要求的男生 / 情侣双方

### 方案 B：温馨陪伴风
- 暖黑/深灰背景 + 珊瑚橙/柔粉点缀
- 话术锦囊设计成聊天泡泡样式
- 圆角更大、渐变更柔和
- 强调「拍照不吵架」的情绪价值
- **适合人群**：注重情感连接、容易紧张的女生

### 方案 C：时尚杂志风
- 高对比黑白 + 高饱和点缀色
- 大胆排版，点评页像杂志内页
- 强调高级感和社交分享欲
- **适合人群**：年轻女性、闺蜜、社交达人
