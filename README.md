# Pose相机 / PoseCam

> 让每个人都能拍出「有情绪、有构图、有故事」的人像照片。

## 一句话产品

一款结合摄影知识库与 AI 视觉的拍照伴侣工具：
**拍摄者**打开相机，AI 实时告诉 TA 该站哪儿、用什么焦段/倍数、怎么构图；
**被拍摄者**通过 AR 姿势引导线知道怎么摆、往哪看、做什么表情；
同时给拍摄者备好能调动对方情绪的「话术锦囊」，让拍照从「沉默社死」变成「开心互动」。

## 核心问题

- 拍的人：不知道机位、焦段、参数，拍出来要么路人照要么废片。
- 被拍的人：越拍越僵硬，动作重复、表情尴尬。
- 关系场景（情侣/闺蜜/亲子）：拍照过程容易变成互相埋怨的小型危机。

## 解题思路

1. **双向引导**：同时服务「拿相机的人」和「被拍的人」。
2. **专业摄影知识库拆解**：把构图、焦段、光线、姿势等专业知识变成实时指令。
3. **AI 视觉实时反馈**：取景器内叠加姿势参考线、构图框、站位提示。
4. **情绪价值话术**：根据场景生成拍摄者可以念的引导语，让被拍者放松、开心、出片。
